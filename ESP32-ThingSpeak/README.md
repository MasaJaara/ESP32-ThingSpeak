# ESP32 Digital Input Monitoring with ThingSpeak

## Project Description

This project uses an ESP32 to read the state of a digital input
connected to GPIO 26. The ESP32 connects to Wi-Fi and sends the
input state to Field 1 of a ThingSpeak channel.

The project is simulated using Wokwi. The input is configured
with the internal pull-up resistor, and its state is displayed
in the Serial Monitor.

## Components

- ESP32
- Digital input connected to GPIO 26
- Wi-Fi connection
- ThingSpeak
- Wokwi simulator
